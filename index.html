    Tipos de documento y nomenclatura

    En HPM coexisten dos convenciones de código, según lo confirmado en HPM-QF-00 (Lista Maestra) y HPM-QI-08:
    1) Documentos rectores del SGC (Manual, Proceso, Guía) — código HPM-[TIPO]-[CONSECUTIVO], sin segmento de área (ej. HPM-QI-08, HPM-QP-07). Aquí "QI"/"QP"/"QM" identifican el tipo de documento, no el área.
    2) Documentos operativos de área (formatos, reportes, instructivos, procedimientos específicos) — código HPM-[ÁREA]-[TIPO]-[CONSECUTIVO] (ej. HPM-QI-FO-101, HPM-MFG-RE-101). Aquí "QI" es el área de Calidad.
    El sistema aplica automáticamente el patrón correcto según el tipo que selecciones en el Alta.

    Este archivo intenta conectarse a Firebase usando el objeto FIREBASE_CONFIG definido al inicio del <script>. Mientras contenga los valores de ejemplo, la app funciona solo con almacenamiento local del navegador.
